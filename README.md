# MovieQuiz App

## Overview
A movie quize game

## Features
- Guess the rating of random movies
- Set highscores

## Tech Stack
- **Language:** Swift
- **Architecture:** MVP
- **Frameworks:** UIKit

## Installation
```bash
git clone https://github.com/BVladimir01/MovieQuiz.git
cd MovieQuiz
open MovieQuiz.xcodeproj
```

### Requirements
- Swift 5.x
- iOS 15+
- Xcode 16+
